# 对账报告设计

## 已确认的产品方向

程序读取调用方给出的本地 CSV 交易文件，校验全部记录后生成一份文本对账报告。只要一条记录无效，本次处理就返回明确错误，并且不输出部分报告。

当前版本不连接数据库、不上传报告、不负责用户认证。输入格式、失败时不产生部分结果和本地运行方式都是对外承诺。

## 原始实现架构提议

- Controller 读取参数、选择文件、格式化报告，并直接读取 Manager 的内部 rows；
- Manager 解析和校验交易，把中间结果写入 Utils 提供的全局可变 store，并调用 Controller 的错误格式化函数；
- Utils 同时保存共享状态、数据类型、文件辅助函数和错误文本；
- 各层可以直接读取 store，Controller 与 Manager 相互依赖。

这些类名、技术分层和共享 store 只是早期实现提议，不是产品方向或公共接口要求。
